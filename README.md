# IDEA Atlas

Special education data for every U.S. school district.

IDEA Atlas brings together public federal data on how school districts carry out the Individuals with Disabilities Education Act: who is served, where students learn, discipline, graduation, and funding. Families and researchers can search by ZIP code, read a district profile, or explore a national map and table.

By Dr. Suman Rath. Live at https://sumanrath.org/tools/idea-atlas/ (coming soon).

## Folders

- `config/` – the list of data sources and settings
- `fetch/` – downloads each source and saves a dated copy
- `clean/` – standardizes district IDs, applies the data rules, calculates rates
- `build/` – makes the map tiles, district pages, and table
- `site/` – the finished website files
- `methods/` – the public methods page
